# 모모 친구용 1.4.19

Windows 바탕화면에서 쓰는 개인 비서입니다. 파일 찾기·읽기·수정, Google Calendar·Drive, Notion을 지원합니다. 기본 친구 말투로 답하며, 문구를 직접 바꾸거나 카카오톡 대화 파일의 실제 응답 예시를 함께 사용할 수 있습니다. 오늘 브리핑은 Google Calendar의 오늘 일정만 읽습니다. 이 버전에는 할 일 관리 서비스가 없습니다.

## 설치

`MomoFriendsSetup-1.4.19.exe`를 실행합니다. 설치 후 바탕화면이나 시작 메뉴의 **비오 비서 (친구용)**을 실행하세요. Python은 필요하지 않습니다. AI 기능을 쓰려면 Codex CLI 또는 Claude Code CLI 중 하나를 설치하고 본인 계정으로 로그인해야 합니다.

채팅창은 기존의 테두리 없는 바탕화면 오버레이를 유지합니다. 기본은 일반 창 순서이며 머리글의 📌 버튼으로 다른 앱 위에 고정하거나 해제할 수 있습니다. 선택한 상태는 다음 실행에도 유지되며, 캘린더 위젯의 표시 방식은 바뀌지 않았습니다.

친구용은 회사용과 함께 설치할 수 있습니다. 친구용 설정·가이드라인·Notion 토큰·Google 로그인 프로필은 `%LOCALAPPDATA%\MomoFriends`에 저장됩니다. 회사용 `%LOCALAPPDATA%\DeskBuddy`의 데이터를 읽거나 옮기지 않습니다. 설치 파일에는 계정 정보나 API 토큰이 들어 있지 않습니다.

자세한 연결 방법은 [사용자 가이드.md](사용자%20가이드.md)를 참고하세요.

일정 메모는 Notion의 **📝일정 메모 → 일정 메모** 데이터베이스에 연결합니다. `회의 메모 기록해줘`라고 하면 이벤트 날짜·시각을 함께 저장하고, `회의 준비 브리핑해줘`라고 하면 같은 일정의 메모를 Drive 자료와 함께 보여줍니다. 해당 페이지와 데이터베이스가 모모의 Notion 연결에서 보이도록 공유해야 합니다.

창 왼쪽 가운데 점 세 개를 왼쪽으로 드래그하면 대화창이 가로로 넓어집니다. 오른쪽 아래 모서리로 가로·세로 크기를 함께 바꿀 수도 있습니다.

톱니 메뉴에서 **다크 민트**를 선택하면 다크모드로 바뀝니다. 선택한 테마는 다음 실행에도 유지됩니다.

카카오톡 대화를 `.txt`로 내보낸 뒤 **톱니 → 카톡 말투 가져오기**에서 파일과 친구의 표시 이름을 선택하세요. 모모는 원본을 복사하지 않고 추린 예시를 `%LOCALAPPDATA%\MomoFriends\chat-style.dpapi`에 Windows 계정으로 암호화해 저장합니다. 답변할 때 관련 예시 최대 6개가 선택한 AI 엔진에 전달됩니다. 예시를 지우려면 **톱니 → 카톡 말투 지우기**를 선택하세요. 대화 파일과 예시는 GitHub 저장소나 설치 파일에 포함되지 않습니다.

말투 문구는 **톱니 → 말투 설정**에서 수정하고 저장할 수 있습니다. **기본값 복원**을 누르면 원래 친구 말투로 돌아갑니다. 카톡 대화 예시를 가져오면 설정한 문구와 예시를 함께 참고합니다. 직접 수정한 문구는 `%LOCALAPPDATA%\MomoFriends\voice-style.txt`에 저장됩니다.

## 일정 알림

모모가 Google Calendar에 추가하고 확인한 일정은 이 PC에 알림으로 저장합니다. 기본값은 시작 1시간·30분·5분 전이며 **톱니 → 일정 알림**에서 끌 수 있습니다. 각 시점에 한 번씩 팝업으로 알립니다. 모모를 통해 일정을 삭제하면 알림도 지웁니다. Google Calendar에서 직접 만든·수정한 일정은 자동 동기화되지 않습니다. 알림 목록은 `%LOCALAPPDATA%\MomoFriends\calendar-alerts.json`에 저장됩니다.

알림 팝업의 **5분 뒤 다시**를 누르면 5분 후 한 번 더 알려줍니다. 미룬 시각은 모모를 재시작해도 유지됩니다.

Google Calendar·Drive 작업은 백그라운드 Chrome에서 진행하며 결과는 기존 모모 대화창에 표시합니다. 로그인이 필요하면 **톱니 → Google 로그인 창 열기**에서 로그인한 뒤 창을 닫으세요.

모모가 Codex CLI를 사용할 때는 앱에서 `gpt-6-luna`를 지정합니다. PC의 Codex 기본 모델 설정은 바꾸지 않습니다.

## 바탕화면 캘린더 위젯

모모를 켜면 작은 달력 위젯이 바탕화면 위, 일반 앱 창 아래에 표시됩니다. 모모의 톱니 메뉴에서 **캘린더 위젯에 캘린더 추가**를 선택하고 Google Calendar의 **설정 → 내 캘린더 → 캘린더 통합 → 비공개 iCal 주소**를 입력하세요. 캘린더가 여러 개면 주소를 하나씩 추가합니다. 위젯에는 해당 캘린더의 실제 일정과 반복 일정이 표시됩니다. 주소는 현재 Windows 사용자 계정으로 암호화하여 저장하며 설치 파일에는 포함되지 않습니다. 주소를 다른 사람과 공유하지 마세요. `public/basic.ics` 공개 주소는 비공개 캘린더에서 404가 나므로 사용하지 마세요.

위젯은 조회 전용입니다. 일정 추가·삭제는 기존 모모 대화로 요청하세요. 모모가 일정을 추가·삭제하면 위젯이 즉시 반영하고 그때 한 번만 다시 조회합니다. 다른 곳에서 바뀐 일정은 위젯의 새로고침 버튼을 누르거나 월을 바꿀 때 가져옵니다. 주기적인 자동 조회는 하지 않습니다. 위젯을 드래그해 옮길 수 있고 톱니에서 숨기거나 연결 주소를 초기화할 수 있습니다. Google Workspace 관리자가 비공개 iCal 주소를 제한했다면 이 방식은 사용할 수 없습니다.
