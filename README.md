# 모모 친구용 1.1.0

Windows 바탕화면에서 쓰는 개인 비서입니다. 파일 찾기·읽기·수정, Google Calendar·Drive, Notion을 지원합니다. 카카오톡 대화 파일을 가져오면 실제 친구의 응답 예시를 참고해 답합니다. 오늘 브리핑은 Google Calendar의 오늘 일정만 읽습니다. 이 버전에는 할 일 관리 서비스가 없습니다.

## 설치

`MomoFriendsSetup-1.1.0.exe`를 실행합니다. 설치 후 바탕화면이나 시작 메뉴의 **모모 비서 (친구용)**을 실행하세요. Python은 필요하지 않습니다. AI 기능을 쓰려면 Codex CLI 또는 Claude Code CLI 중 하나를 설치하고 본인 계정으로 로그인해야 합니다.

친구용은 회사용과 함께 설치할 수 있습니다. 친구용 설정·가이드라인·Notion 토큰·Google 로그인 프로필은 `%LOCALAPPDATA%\MomoFriends`에 저장됩니다. 회사용 `%LOCALAPPDATA%\DeskBuddy`의 데이터를 읽거나 옮기지 않습니다. 설치 파일에는 계정 정보나 API 토큰이 들어 있지 않습니다.

자세한 연결 방법은 [사용자 가이드.md](사용자%20가이드.md)를 참고하세요.

창 왼쪽 가운데 점 세 개를 왼쪽으로 드래그하면 대화창이 가로로 넓어집니다. 오른쪽 아래 모서리로 가로·세로 크기를 함께 바꿀 수도 있습니다.

톱니 메뉴에서 **다크 민트**를 선택하면 다크모드로 바뀝니다. 선택한 테마는 다음 실행에도 유지됩니다.

카카오톡 대화를 `.txt`로 내보낸 뒤 **톱니 → 카톡 말투 가져오기**에서 파일과 친구의 표시 이름을 선택하세요. 모모는 원본을 복사하지 않고 추린 예시를 `%LOCALAPPDATA%\MomoFriends\chat-style.dpapi`에 Windows 계정으로 암호화해 저장합니다. 답변할 때 관련 예시 최대 6개가 선택한 AI 엔진에 전달됩니다. 예시를 지우려면 **톱니 → 카톡 말투 지우기**를 선택하세요. 대화 파일과 예시는 GitHub 저장소나 설치 파일에 포함되지 않습니다.
